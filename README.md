# PurePlay — Minimalist Floating Media Widget for Rainmeter

A clean, lightweight, transparent white media widget for Rainmeter featuring smooth 60 FPS click-and-drag seeking, scroll-to-seek, and seamless UTF-8 marquee text.

## ✨ Features
- **Full Interactive Progress Bar:** Click anywhere to jump, click-and-hold to scrub smoothly across the screen, or scroll mouse wheel (`±5%`).
- **Seamless Marquee Title:** Auto-centers short titles and smoothly loops long UTF-8 track names.
- **Zero-Clutter Design:** Floating white typography with subtle drop shadows that blend into any wallpaper.

## 📥 Download & Compatibility
Choose the installer matching your Rainmeter version:
- **Rainmeter 5.0+ (Recommended):** `PurePlay_v1.1_Rainmeter5.0+.rmskin` *(Native `PlayerName=Windows` integration)*
- **Rainmeter 4.5.x:** `PurePlay_v1.0_Rainmeter4.5.rmskin` *(Legacy stable build)*
